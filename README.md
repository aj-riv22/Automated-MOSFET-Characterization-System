# Automated MOSFET Characterization System

This project is a PlatformIO-based firmware setup for an Arduino Nano R4 that characterizes MOSFET behavior by sweeping a DAC output, reading the resulting sensed voltage, and streaming the data to a serial monitor or a browser-based plotting interface.

The repository includes:
- PlatformIO firmware in `src/main.cpp`
- A browser dashboard in `web/index.html`
- Example MATLAB plotting in `matlab/serialPlot.m`
- Supporting experiment sketches in `experiments/`

## Hardware
- Arduino Nano R4
- MOSFET test circuit and current amplifier as described by the project wiring
- USB cable to connect the board to your computer

## Software requirements
- Git
- Visual Studio Code
- PlatformIO IDE extension (recommended) or PlatformIO Core CLI
- A modern browser such as Chrome or Edge for the web dashboard

## 1) Install Git

If Git is not already installed:

- Windows: install Git for Windows from https://git-scm.com/
- macOS: `brew install git`
- Linux: `sudo apt install git` or the equivalent for your distro

Verify:

```bash
git --version
```

## 2) Install VS Code

Download and install Visual Studio Code:

https://code.visualstudio.com/

## 3) Install PlatformIO

### Option A: Install the VS Code extension (recommended)
1. Open VS Code.
2. Go to Extensions.
3. Search for `PlatformIO IDE`.
4. Install the extension.
5. Reload VS Code when prompted.

### Option B: Install PlatformIO Core (CLI)
If you prefer terminal-based setup, install PlatformIO Core:

- Windows (PowerShell):

```powershell
pip install platformio
```

- macOS/Linux:

```bash
python3 -m pip install platformio
```

Verify:

```bash
pio --version
```

## 4) Clone the repository

From a terminal:

```bash
git clone https://github.com/aj-riv22/Automated-MOSFET-Characterization-System.git
cd Automated-MOSFET-Characterization-System
```

If you already have the project locally, just open that folder in VS Code.

## 5) Open the project in VS Code

1. Launch VS Code.
2. Open the cloned folder: `Automated-MOSFET-Characterization-System`
3. If using the PlatformIO extension, it should detect the project automatically.
4. The project config file is `platformio.ini` and already targets the Arduino Nano R4 board.

## 6) Build and upload the firmware

### Using PlatformIO in VS Code
1. Connect the Nano R4 to your computer with USB.
2. Select the correct serial port if prompted.
3. In the PlatformIO sidebar, click the build icon and then the upload icon.
4. Alternatively, use the terminal:

```bash
pio run -e nano_r4
pio run -e nano_r4 -t upload
```

### Using PlatformIO CLI directly

```bash
cd Automated-MOSFET-Characterization-System
pio run -e nano_r4 -t upload
```

If the board is not detected, check:
- The USB cable is connected and working
- The correct COM port / device is selected
- The board is recognized by the OS

## 7) Monitor the serial output

To view the data being generated by the board:

```bash
pio device monitor -b 115200
```

You should see data in the format:

```text
0.000,0.000
0.025,0.001
0.050,0.002
...
```

This is the applied voltage and sensed voltage for each sweep step.

## 8) Run the browser dashboard

The repo includes a lightweight web interface in `web/index.html` for visualization.

### Option A: Open directly in a browser
1. Open `web/index.html` in a browser that supports Web Serial (Chrome or Edge recommended).
2. Connect to the board's serial port when prompted.
3. Start the sweep or data collection from the page.

### Option B: Serve it locally
From the project root:

```bash
cd Automated-MOSFET-Characterization-System
python -m http.server 8000
```

Then open in a browser:

```text
http://localhost:8000/web/
```

## 9) MATLAB plotting (optional)

If you want to analyze the captured serial data in MATLAB, open `matlab/serialPlot.m` and adjust the serial port settings if needed.

## 10) Typical workflow

1. Install Git, VS Code, and PlatformIO.
2. Clone the repository.
3. Open the project in VS Code.
4. Connect the Nano R4.
5. Upload the firmware with PlatformIO.
6. Use the serial monitor or browser dashboard to collect data.
7. Save the output and analyze it in MATLAB or another plotting tool.

## Notes
- The project is configured for `board = nano_r4` in `platformio.ini`.
- If the build fails, make sure the PlatformIO platform packages are up to date:

```bash
pio pkg update
```

- If you want to clean and rebuild:

```bash
pio run -t clean
pio run -e nano_r4
```

## Troubleshooting

### PlatformIO not recognized
Try restarting VS Code after installing the extension or open a new terminal after installing PlatformIO Core.

### Board not detected
- Reconnect the USB cable
- Try another USB port
- Check that the operating system sees the board as a serial device
- Confirm the correct board is selected in the PlatformIO config

### Serial monitor shows nothing
- Make sure the firmware is uploaded successfully
- Check the selected serial port
- Confirm the baud rate is `115200`
